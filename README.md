# ITZFIZZ Motion Experience

A scroll-driven hero animation concept created for the ITZFIZZ frontend assignment. The page combines an animated headline, illustrative metrics, and a car visual controlled by scroll.

## Live Demo

[View the live experience](https://itzfizz-motion-experience--sindujau11.replit.app)

## Features

- Staggered headline and metric reveal on page load
- Scroll-linked car movement using GSAP ScrollTrigger
- Responsive layout for desktop and mobile
- Reduced-motion support

## Tech Stack

- React
- Vite
- Tailwind CSS
- GSAP and ScrollTrigger
